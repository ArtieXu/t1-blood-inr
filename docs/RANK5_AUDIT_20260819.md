| 拟合用的 TI | M0 | Mz/M0 | **T1 (ms)** | R² |
|---|---:|---:|---:|---:|
| 50 + 200n | 300.428 | −0.86187 | **1871.843** | 0.996041 |
| 63 + 200n | 300.428 | −0.87485 | **1871.843** | 0.996041 |

（存档值 T1 = 1880.831, R² = 0.995674；差 0.5%，是优化器/权重差异，不影响下面的结论。）

### 4.4 从这张表能得出的四条结论

**(1) 失败的是 prior 的表达上限，不是优化器。**
oracle 投影是**任何**硬 rank-5 方法的天花板——没有算法能超过它。天花板本身 grad = 16.4%，超阈值 9.4%。所以在换 prior 之前，调 INR 容量、学习率、loss 权重、步数都不可能过这个 gate。这条把 `RANK5_MODEL_GAP_DETECTED` 从「观察」升级成了「可证明」。

**(2) 加大物理字典的秩基本无效。** K=5→8，grad 只从 0.1642 降到 0.1527（−7%）；要到 K=10 才勉强压线。这与 `MIGRATION_5070.md:47`「rank-7 物理字典仍然 fail」完全一致，本次给出了整条曲线。**不要去做「把 K 从 5 加到 6/7」的扫描，边际收益已经量化过了。**

**(3) 扩 Mz 或 T1 网格没用——这是个新的否定结果。**
`PROGRESS_AND_OUTLOOK` §5 把 Mz 范围列为「待选工程参数」（-1..0 / -1..-0.8 / -1..1）。实测：Mz 扩到 −1..+1，grad 从 0.16417 变成 0.16414；T1 扩到 100–8000，grad 变成 0.1645（略微更差）。**这一维可以直接从待扫参数表里划掉。**

**(4) 「保留主 T1 成分 + 残差模态」可行，但代价是 4 个模态，不是 1–2 个。**
物理 K=5 + 4 个数据自适应残差模态（总秩 9）是通过三项 gate 的最小配置：0.0276 / 0.1210 / 0.1445。
它与数据驱动 SVD K=7（0.0266 / 0.1210 / 0.1455）几乎打平——也就是说，**坚持保留 5 个物理基向量要多付 2 个自由度**。换来的是 T1 定量的物理解释不受影响，且符合 `AGENTS.md:38` 允许的「small residual dynamic subspace」。

**(4b) 但这些「残差模态」行是双重乐观的上界，必须标清楚。**
物理 K 那几行的基是**先验固定**的（来自 IR 字典，与数据无关），所以那个天花板是真能达到的——只要重建算法找得到正确的系数。
而「残差模态」和「数据驱动 SVD」那几行的**基本身就是从 target 算出来的**，是 oracle。实际重建时你没有 target，这 4 个模态得从别处估，估计误差会直接进 prior。所以 0.1445 是**上界的上界**，实际必然更差。这决定了 §6 里那个决策点必须一并回答「残差模态从哪来」。

### 4.5 一个必须写进文档的陷阱 **[执行]**

notebook cell 6 有：

```python
assert retained_energy > 0.99999
```

实测：rank-5 保留了字典自身能量的 **99.9996%**（丢 4.4e-6）。
同一个 rank-5 basis 投影真实解剖时：**复数能量丢 5.9%，梯度能量丢 16.4%，高通能量丢 19.4%。**

原因：字典能量是在**逐曲线 L2 归一后、对 T1 网格均匀加权**下算的，跟真实图像的 T1 直方图无关；而残差 `(I-P)X` 的空间频谱比 `X` 本身平坦得多，所以它在边缘/高频域的相对权重被放大三个量级。
**`retained_energy` 这个 assert 提供的是虚假信心，它跟 image gate 没有任何单调关系。** 建议在 notebook 里把这句 assert 降级为记录项，并把 image-domain 投影误差作为真正的准入指标。

- **「rank-5 不够」不依赖阈值精确取值。** hp = 0.1936 超阈值 **29%**，是决定性的；grad = 0.1642 只超 9.4%。除非把 hp 阈值放宽到 0.20 以上，否则这个结论稳。
- **「加几个模态才够」高度依赖这个没有推导的阈值。** +1/+2/+3 分别是 0.1763 / 0.1615 / 0.1531，全都贴着 0.15。阈值挪到 0.16，答案就从「+4」变成「+2」。

**建议在 Step 3 决策之前，给 0.15 一个可辩护的锚点。** 三个候选：

1. **噪声地板**：由实测噪声水平推出 highpass NRMSE 的统计下限，低于它的差异没有意义。
2. **重复性地板**：GASSP1 vs GASSP2 同一受试者两次扫描之间的 grad/hp NRMSE。低于这个数的差异不可重复，卡再严也没用。这是最有说服力的锚点。
3. **参考方法**：现有 CG 管线的表现。

**锚点 3 我算了，但它不成立**——`cg_predeblur.mat`（实测 GASSP1、每个 TI 一条臂的 CG 重建）对 `full_spiral_preb0_target.mat`（全采样参考）：

| | magnitude | gradient | highpass |
|---|---:|---:|---:|
| 现有 CG（实测数据） | 0.497 | **1.328** | **1.462** |
| 物理 rank-5 oracle 投影 | 0.043 | 0.164 | 0.194 |
| locked gate | <0.05 | <0.15 | <0.15 |

（幅度相关 r = 0.795，质心相差 < 2 像素，量级一致 → 是真实的欠采样误差，不是配准或缩放问题。）

两者相差约 **9 倍**，但**这不是同一个数据 regime**：CG 是从每 TI 一条螺旋臂的实测数据重建的，参考是全采样的。所以它不能用来定阈值。
它说明的是另一件事：**0.15 是一个「回顾性阶段的内部自洽要求」，不是物理或临床门槛。** 别把它读成「达到 0.15 就是好图像」。
